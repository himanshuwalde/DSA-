# DSA 🧠

A growing collection of Data Structures & Algorithms solutions and practice problems, organized by topic. Built up over time as ongoing practice for problem-solving and interview preparation.

## 📌 About

This repository is a topic-wise archive of DSA practice — each folder groups solutions and exercises for a specific data structure or algorithmic technique, making it easy to revisit and review concepts by category.

## 📂 Topics Covered

| Folder | Topic |
|---|---|
| `Arrays` | Array-based problems |
| `Strings` | String manipulation problems |
| `Linked List` | Singly/doubly linked list operations and problems |
| `Stacks` | Stack-based problems |
| `Queues` | Queue-based problems |
| `HashMaps` | Hash map / dictionary-based problems |
| `HashSets` | Hash set-based problems |
| `Binary Tree` | Binary tree traversal and problems |

| `Heaps` | Heap / priority queue problems |
| `Graphs` | Graph traversal and algorithms |

| `Bit Manipulation` | Bitwise operation problems |

*(New folders and problems are added as practice continues.)*
